Branches

Linhas paralelas de trabalho, sem quebrar a main

Uma demanda que não cabe em um commit

V Demanda: tela de login
  • 1 formulário de login login.php
  • 2 validação da senha login.php
  • 3 sessão do usuário sessao.php
Enquanto isso, a main precisa continuar funcionando. Metade de um login não pode ir para o ar.

Na Iron Systems o padrão é commitar direto na main. Para o que leva vários commits, quem preferir usa uma branch local curta.

projeto-rpa — main
$ 
Switched to a new branch 'feature/login'

Uma branch é só um ponteiro para um commit.
Criar uma é instantâneo e barato.
